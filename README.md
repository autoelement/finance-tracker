# finance-tracker

Excel-ზე დაფუძნებული ფინანსური ანალიზატორი — ერთი თვითმყოფადი HTML აპლიკაცია (ქართული ინტერფეისი).

## რას აკეთებს

- 📥 **Excel/CSV იმპორტი** (`.xlsx`, `.xls`, `.csv`) — drag & drop ან ღილაკით
- 🔗 **სვეტების ავტო-ამოცნობა** — თარიღი, აღწერა, თანხა, ტიპი, კატეგორია
- ⚖️ **ავტო-დარისხება** — შემოსავალი vs ხარჯი (ტიპის სვეტით, ნიშნით, ან ხელით)
- 🏷️ **ავტო-კატეგორიზაცია** — საკვანძო სიტყვებით (ხელფასი, საკვები, ტრანსპორტი, ქირა, კომუნალური, ჯანმრთელობა…)
- 📊 **სტატისტიკა** — შემოსავალი, ხარჯი, მოგება/ზარალი, მარჟა
- 📈 **გრაფიკები** — თვიური P&L, შემოსავალი vs ხარჯი, კატეგორიების განაწილება, კუმულაციური ბალანსი
- 🔎 ცხრილი ძებნით, ფილტრით, დახარისხებით და **CSV ექსპორტით**

## კონფიდენციალურობა

აპლიკაცია **მთლიანად ბრაუზერში მუშაობს**. Excel ფაილი არსად არ იგზავნება — დამუშავება ხდება შენს მოწყობილობაზე, მონაცემები ინახება მხოლოდ ბრაუზერის `localStorage`-ში.

## გაშვება

უბრალოდ გახსენი `index.html` ბრაუზერში, ან ჩართე GitHub Pages და გამოიყენე live ლინკი.

## ტექნოლოგიები

- Vanilla JS (build არ სჭირდება)
- [SheetJS](https://sheetjs.com/) — Excel-ის წაკითხვა
- [Chart.js](https://www.chartjs.org/) — გრაფიკები
